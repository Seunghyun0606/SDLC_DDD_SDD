## 3. GAP-RE-001A — Source Drift Detection + Artifact STALE Propagation
**판정: CORE IMPLEMENTED / VALIDATED**

Core 입력:
- baseline source manifest
- observed source manifest
- artifact evidence index
- 명시적 reverse propagation edge

Core 출력:
- Source ADDED/MODIFIED/DELETED/UNCHANGED
- `STALE_SOURCE_EVIDENCE`
- `STALE_PROPAGATED`
- `CHECK_REQUIRED_REVERSE`
- Reverse Candidate

안전 원칙:
- 기존 문서를 자동 재작성하지 않는다.
- Business Truth를 자동 변경하지 않는다.
- `CHECK_REQUIRED`는 자동으로 상위까지 연쇄 전파하지 않는다.
- STALE 전파는 명시적 Edge가 있을 때만 수행한다.
- 이미 현재 Source Hash로 재생성된 Artifact는 과거 baseline이 달라도 stale 처리하지 않는다.
