- Adapter 미구현 시 `PARTIAL_PROJECT_ADAPTER_REQUIRED`
- `찾지 못함`을 `영향 없음`으로 판정하지 않음

- Source manifest baseline/observed 비교
- Artifact recorded Source Hash freshness 검증
- 직접 STALE 판정
- 명시적 Edge를 통한 STALE/CHECK_REQUIRED 전파
- Cycle 안전성
- 신규 Source가 unrelated Artifact를 자동 stale하지 않음
- 최신 hash로 이미 재생성된 Artifact를 stale하지 않음
- Artifact/Business Truth 자동 rewrite 금지
