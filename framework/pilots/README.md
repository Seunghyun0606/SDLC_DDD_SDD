# Framework Pilot Assets

이 디렉터리는 SDLC Framework 자체의 Pilot/Empirical/Validation Evidence를 보관한다.

- 일반 Project Scaffold에 배포하지 않는다.
- 실제 프로젝트 문서 SoT로 사용하지 않는다.
- `history/`는 과거 Version별 Pilot 산출물 보존용이다.
- `legacy/`는 이전 `docs/00_관리`에 섞여 있던 Framework 실증/검증 결과를 분리한 것이다.

프로젝트 실행 중 생성되는 관리 View는 `docs/00_관리/`를 사용한다.
