# v1.5.3-rc.2 Runtime Overlay Resolution Delta

## 목적

v1.5.3-rc.1에서 구조로만 정의했던 Core/Overlay 경계를 실행 가능한 Runtime Materialization으로 보강한다.

## 변경

- `sdlc/scripts/resolve_overlay.py` 추가
- Overlay manifest는 dependency-free JSON 사용
- Effective Rule/Skill/Template/Standard를 `sdlc/runtime/effective/`에 materialize
- 적용 순서: Core → Preset → Project → Domain → Local
- Markdown H2 Section 단위 append와 token replacement 지원
- Rule/Standard fragment는 별도 effective file로 materialize
- `effective-manifest.json`에 layer/path/file SHA provenance 기록
- 잘못된 Section, missing target, path traversal은 fail-closed

## 설계 원칙

1. Core 원본은 수정하지 않는다.
2. Overlay는 차이만 표현한다.
3. 합성 결과는 Generated View이며 Custom SoT가 아니다.
4. Overlay 적용 후 Harness Structure/Continuity 검증을 다시 수행한다.
5. Source Evidence/Business Truth invariant는 Project Custom으로 약화할 수 없다.
