# Runtime Contracts

이 위치에서 프로젝트 실행에 사용되는 것은 `contracts/`다.

과거 설계 Baseline, Candidate, Review, Validation, Session 기록과 Framework Changelog/Branch metadata는 `framework/design/`으로 이동했다.

장기적으로 Runtime 계약은 `sdlc/contracts/`로 독립시키는 것이 목표지만, 현재 Runtime/Validator 참조가 많아 `sdlc/design/contracts/` 경로를 compatibility boundary로 유지한다.
