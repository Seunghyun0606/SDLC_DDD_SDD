# 고객 기능정의서 — 탄력근로제 일일 근무계획

> Requirement: `RQ-FLEX-PLAN-001`
> 상태: `REVIEW_REQUIRED`

## 1. 업무 목적

탄력근로제 근무자가 매일 예정 근무시간을 10분 단위로 등록하여 실제 근태집계/마감에서 사용할 계획 기준을 제공한다.

## 2. 6W 업무정의

| 관점 | 고객 View |
|---|---|
| 누가 | ESS 탄력근로제 권한을 가진 근무자 |
| 언제 | 매일, 예정 근무일의 계획을 등록하거나 확인할 때 |
| 어디서 | ESS > 근태/휴가 > 탄력근로제 근무계획 |
| 무엇을 | 근무일자, 근무유형, 시작시간, 종료시간, 예상근무시간, 상태 |
| 어떻게 | Calendar에서 날짜 선택 → 시간 입력 → 검증 → 저장/수정 |
| 왜 | 계획 근무시간을 근태집계/마감 기준으로 사용하고 미입력을 예방하기 위해 |

## 3. 화면 구성

```text
[월 선택] [조회]

┌──────────── 근무 Calendar ────────────┐
│ 날짜별 계획/상태 표시                 │
└──────────────────────────────────────┘

[선택일 상세]
근무일자      [YYYY-MM-DD]
근무유형      [탄력근무]
시작시간      [HH:MM]
종료시간      [HH:MM]
예상근무시간  [Read Only]
상태          [Read Only]

[저장] [수정] [기본값 설정]
```

## 4. 주요 업무 규칙

1. 탄력근로제 대상자만 입력할 수 있다.
2. 시간은 10분 단위로 선택한다.
3. 시작시간은 종료시간보다 이전이어야 한다.
4. 사원/근무일자별 1개의 계획을 유지한다.
5. 확정된 계획은 해당 화면에서 직접 수정하지 않는다.
6. 예상근무시간은 입력한 시작/종료시간을 기준으로 계산한다.

## 5. CRUD

| 기능 | 처리 |
|---|---|
| 월/일 조회 | 조회 |
| 최초 계획 저장 | 등록 |
| 기존 계획 저장 | 수정 |
| 계획 삭제 | 이번 Scope 제외 |
| 개인 기본값 | 조회/등록/수정 |

## 6. 연계

- 저장된 근무계획은 근태집계/근태마감에서 참조한다.
- 미입력자는 알람메일 대상 후보가 된다.
- 전자결재는 본 화면 Scope에서 제외한다.

## 7. 완료조건

- 09:00~18:10 같은 10분 단위 계획 저장 가능
- 09:05 입력 차단
- 시작>=종료 입력 차단
- 기존 계획이 있으면 수정 처리
- 확정계획 수정 차단
- 월 Calendar/일 상세 조회 가능
- 개인 기본값 사용 가능
