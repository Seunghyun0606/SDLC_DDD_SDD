## Extraction Result from XLSX Alone

### OBSERVED
- 저장/등록, 수정, 조회가 필요함
- Calendar 조회가 필요함
- 예상근무시간 조회가 필요함
- 기본값 설정 CRUD 일부가 필요함
- 근무시간 알람 메일 송신이 필요함
- 10분 단위 근무계획을 다룸

### OPEN
XLSX 원문에는 다음이 없다.

- Who: 누가 사용하는가 / 어떤 권한인가
- When: 매일인지, 월 단위인지, 특정 Trigger인지
- Where: 메뉴/화면/채널
- Why: 왜 근무계획을 등록해야 하는가
- Field: 정확히 어떤 입력항목인가
- Validation: 시작/종료시간, 중복, 마감 이후 수정 Rule
- Integration: 근태마감/집계/전자결재와 실제 연결관계
- Physical Data: Table/Column/Key/Common Code

따라서 XLSX만으로 `개발 상세설계 완료`를 선언하지 않는다.
