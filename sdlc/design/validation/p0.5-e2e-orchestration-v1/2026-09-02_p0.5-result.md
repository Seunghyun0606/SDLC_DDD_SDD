## 4. Truth Guard

P0.5 `/check`는 다음 혼동을 명시적으로 방지한다.

- Candidate != Canonical
- Synthetic Fixture != Production Source
- AC/TC Contract Coverage != Runtime PASS
- Source Behavior != Business Truth

따라서 이전 단계가 부분적으로 성공했더라도 Release Ready로 자동 승격하지 않는다.

## 5. Cross-stage Identity Guard

동일 Work Unit의 단계 사이에서 다음을 기계적으로 확인한다.

- Review `source_group_id`가 Normalization Group에 존재
- Reverse Sync `source_group_id`가 Review와 동일
- Verification `rq_group_candidate_id`가 Review와 동일
- Normalization Source Requirement ID 집합과 Review 집합이 동일
- Source Count가 실제 ID 개수와 동일

불일치 시 상태를 생성하지 않는다.

주요 오류 코드:

- `E2E-002`: Normalization Group 없음
- `E2E-003`: Reverse Sync Group mismatch

- `E2E-006/007`: Source Count mismatch
- `E2E-101`: Blocker가 있는데 READY_FOR_RELEASE
