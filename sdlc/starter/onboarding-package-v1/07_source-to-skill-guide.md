# 07. Existing Source → Skill Candidate Guide

## 목적
기존 Source에서 발견한 **반복 가능한 프로젝트 규칙/탐색방법/구현패턴**을 Skill Candidate로 만든다.

## Skill화 대상
- JSP→Controller→Service→Mapper 탐색
- Program ID→파일 Mapping
- Transaction/Error/Logging Pattern
- MyBatis Insert/Update/MERGE Pattern
- Code Master 조회
- Effective Period 처리
- 고객 XLSX/PPT Extraction Mapping
- Test Profile/Regression Command

## Skill화 금지
- 특정 RQ 전용 업무정책
- 현재 Bug를 표준으로 일반화
- 미확인 Code 값
- Secret/개인정보
- 1회성 Hotfix

## Candidate 조건
다음 중 2개 이상:
- 2개 이상 Program 반복
- Project 표준문서 명시
- 개발리드 확인
- Source에서 일관 관찰
- 반복 검색비용 감소

## 상태
`CANDIDATE → REVIEWED → ACTIVE → DEPRECATED`

## 기본 구조
- Purpose
- When To Use
- Required Input
- Retrieval Strategy
- Steps
- Output Contract
- Quality Check
- Alerts
- Do Not
- Examples
- Evidence / Verified Revision

Skill은 Current Source Evidence를 대체하지 않는다.
