# 작업지시서 — HRIS / hunel

> **역할**: 업무정의서에서 정한 기능과 업무 규칙을 실제 hunel 프로그램과 소스 변경으로 연결하는 개발자용 구현 명세입니다.
>
> - 업무 의미를 여기서 다시 정의하지 않습니다.
> - 하나의 업무/기능 단위에 여러 Program ID가 있으면 Program별로 이 문서를 생성할 수 있습니다.
> - hunel 고유 구현 방식(JSP + Java + XML, ibsheet, doAction, 권한 Framework, Procedure 연동)은 이 문서에서 상세히 다룹니다.
> - 소스 수정은 `소스 변경 범위`에 포함된 대상과 추가로 확인된 승인 대상 안에서 수행합니다.
> - 사용자는 이 Template의 표나 빈칸을 직접 작성하지 않습니다. Agent가 실제 소스와 개발표준을 먼저 분석해 초안을 만들고, 사람 결정이 필요한 항목만 질문합니다.
> - 수정이 필요하면 `Procedure 파라미터 영향만 다시 검토해줘`, `소스 변경 범위에 XML 파일을 추가해줘`처럼 절 제목이나 내용을 자연어로 지정하면 됩니다. Agent는 숨겨진 Block 식별자를 사용해 정확한 위치를 찾습니다.
> - 사용자가 바로 답할 수 없는 질문은 `추가 확인이 필요한 사항`에 남겨 개발 시작 전, 테스트 전 또는 최종 검증 전에 다시 확인합니다.
