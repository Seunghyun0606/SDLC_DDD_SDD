# 개발 작업 지도

> 이 문서는 Agent가 현재 요구·설계·소스 정보를 바탕으로 작성하는 개발자용 작업 지도입니다. 사용자는 빈칸을 처음부터 작성하지 않고, 작업 범위와 진행 상태를 확인하고 필요한 결정만 합니다.
>
> **업무/기능 단위는 함께 변경·검증되는 기능 경계이고, 프로그램/소스는 실제 구현 단위입니다.** 하나의 업무/기능 단위가 여러 프로그램과 소스를 포함할 수 있습니다.
>
> 수정이 필요하면 문서의 절 제목이나 내용을 자연어로 지정하면 됩니다. Agent는 내부 Block 식별자를 사용해 정확한 위치를 찾아 반영합니다. 즉시 답할 수 없는 질문은 아래 `추가 확인이 필요한 사항`에 남겨 다음 작업에서 다시 확인합니다.
