# Skill Guide Compatibility Link

기존 링크 호환용 문서다. `/work`, `/change`, `/check`의 사용자 Mental Model은 `docs/00_시작/START_HERE.md`를 기준으로 한다.

- `/work`: 설계/Evidence/Source Mapping/AS-BUILT/Verification 보완
- `/change`: Requirement/Business Rule/TO-BE/Scope 변경
- `/check`: 현재 상태/Alert/다음 작업 확인

세부 규칙을 이 파일에 중복 유지하지 않는다.
