# Compatibility Notice — Custom Scaffold Guide

이 경로는 이전 Harness package contract와 외부 링크 호환을 위해서만 남아 있다.

현행 Customization은 `sdlc/custom/project/`와 `.sdlc/project.yaml`을 기준으로 하며 다음 문서를 사용한다.

- `02_PROJECT_설정가이드.md`
- `03_TAILORING_설정가이드.md`
- `04_TEMPLATE_및_산출물_가이드.md`

과거 `documents.internal.profile` 중심의 Custom Scaffold 본문은 삭제되었으며 신규 Project Scaffold에는 이 compatibility notice를 배포하지 않는다.
