# Compatibility Notice — 요구사항 정의 예시

이 파일명은 과거 가이드 링크 호환을 위해 남아 있다.

v1.10.1 신규 프로젝트의 기본 Engineering 문서는 별도 `요구사항 정의서`가 아니라 **Work Map + Work Unit SDD + 필요 시 Program Spec** 구조다.

```text
docs/10_engineering/<TARGET>/
├─ 00_work-map.md
├─ specs/<TARGET>.md
└─ programs/<TARGET>.md   # 필요할 때만
```

따라서 이 경로의 과거 요구사항 정의 예시를 신규 Project 산출물 Template으로 사용하지 않는다.

현재 작성 수준은 다음 문서를 기준으로 이해한다.

- `04_TEMPLATE_및_산출물_가이드.md`
- `sdlc/templates/engineering/standard/00_work-map.md`
- `sdlc/templates/engineering/standard/work-unit-sdd.md`
- 필요 시 `sdlc/templates/engineering/standard/program-spec.md`

Requirement Intake 결과는 `examples/요구사항_인입_완성예시.md`를 참고한다.
