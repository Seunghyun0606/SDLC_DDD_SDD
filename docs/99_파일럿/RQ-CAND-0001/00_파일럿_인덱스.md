# RQ-CAND-0001 Workflow Pilot Index

> 입력은 실제 첨부 `요구사항목록.xlsx`의 `REQ_TM_FL001~003`이다. Source 이후 단계는 실제 Application Source가 아니라 **SIMULATED_SOURCE_FIXTURE**를 사용한다.

## 30초 요약
- 실제 요구 입력: 3건
- Pilot RQ: `RQ-CAND-0001`
- 업무: 탄력근로제 개선 최초근무계획 자동 설정
- Source: `SIMULATED_SOURCE_FIXTURE`
- 최종 판정: `PILOT_STRUCTURAL_PASS / REAL_SOURCE_PENDING`
