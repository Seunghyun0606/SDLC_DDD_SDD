# 탄력근로제 개선 최초근무계획 자동 설정 — 고객 요구사항 협의서

## 문서 목적
첨부 요구사항 목록에서 확인된 요청을 고객과 같은 언어로 확인하고, 설계 전에 추가로 결정해야 할 내용을 분리한다.

## 한눈에 보기
탄력근로제 최초 근무계획과 관련해 **저장**, **조회**, **기본 근무스케줄을 이용한 최초 계획 자동 생성·저장** 기능이 요청되어 있다. 현재 요구사항만으로는 자동 생성 시점, 대상 사용자, 기존 데이터가 있을 때의 처리 방법까지는 확정할 수 없다.

## 요청 배경
- 요구사항 그룹: `RQ-CAND-0001`
- 고객 원본: `요구사항목록.xlsx`
- 원본 요구사항 ID: `REQ_TM_FL001`, `REQ_TM_FL002`, `REQ_TM_FL003`

## 고객 요청 내용과 기대 결과
1. 탄력근로제 근무계획을 저장할 수 있어야 한다.
2. 저장된 탄력근로제 근무계획을 조회할 수 있어야 한다.
3. 최초 근무계획이 필요한 경우 기본 근무스케줄을 기준으로 계획을 생성하고 저장하는 기능이 필요하다.

## 고객과 함께 확인할 내용
- '최초'의 기준은 무엇인가: 사용자 최초 등록, 월/주기 최초 생성, 특정 제도 적용 최초 등
- 자동 생성은 어떤 화면/업무 시점에서 실행되는가
- 기본 근무스케줄은 어느 기준정보를 사용하며 적용 우선순위는 무엇인가
- 이미 근무계획이 존재할 때 자동 생성 요청이 들어오면 거절/덮어쓰기/병합 중 어떤 정책을 적용하는가
- 생성 대상자 범위와 실행 권한은 누구에게 있는가
- 저장 실패 또는 일부 생성 실패 시 고객이 기대하는 처리 방식은 무엇인가

## 합의된 내용
현재 원본 요구사항에서 확인 가능한 내용은 저장, 조회, 기본 근무스케줄 기반 자동 생성·저장의 필요성까지이다. 위 확인 질문에 대한 답변은 아직 제공되지 않았다.

## 미확정 사항
위 질문에 해당하는 업무 규칙은 `OPEN` 상태이며 임의로 확정하지 않는다.
