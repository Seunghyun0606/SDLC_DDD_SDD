# 전체 작업 목록

> 이 파일은 `전체작업목록.xlsx`와 동일한 Canonical Work Item의 사용자 View다. 담당자/일정/공수는 선택 입력이다.

```mermaid
flowchart LR
    P[프로젝트] --> M[마일스톤]
    M --> R[요구사항]
    R --> F[세부기능]
    F --> G[프로그램]
    G --> T[작업]
    T --> V[완료기준/테스트]
```
